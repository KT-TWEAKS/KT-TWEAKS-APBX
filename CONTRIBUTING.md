# Contribuindo ao KT APBX

Obrigado por melhorar o catálogo público. Abra uma issue antes de propor mudanças grandes e mantenha cada pull request focado em um único objetivo.

## Antes de enviar

1. Execute `npm ci` e `npm run build`.
2. Não publique links de download, hashes ou playbooks sem validação pelo fluxo oficial.
3. Explique o impacto da mudança e inclua capturas para alterações visuais.

Ao contribuir, você concorda com o [Código de Conduta](CODE_OF_CONDUCT.md) e a [Política de Segurança](SECURITY.md).
