# Código de Conduta

Participantes devem ser respeitosos, colaborar de boa-fé e manter discussões técnicas no escopo do projeto. Não são aceitos assédio, discriminação, ataques pessoais, exposição de dados ou instruções maliciosas.

Reporte incidentes à equipe por uma issue privada de segurança. A manutenção pode editar ou remover conteúdo que viole estas regras.
